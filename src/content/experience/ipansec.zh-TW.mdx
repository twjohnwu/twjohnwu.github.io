  - 做了 A4P，一個 APK 安全分析的全端平台。Python subprocess 呼叫本機的 MobSF 分析 Android APK 檔，網頁爬蟲（與兩位爬蟲工程師協作開發）把產生的報表頁抓下來，重新整理成結構化的安全報告。公司拿到資安實驗室認證，A4P 是關鍵之一。十年後在 Cedars 做 AI Code Review，我把同一套架構搬出來再用一次，只是 MobSF 的位置換成了 LLM API。
  - 交付法務部調查局（MJIB）的 IP 黑名單管理系統，整合硬體網路管理設備，並把 ELK 後端的資料視覺化。
  - 帶 4 人的前後端團隊做 IoT 裝置市集。客製化的 Node-RED build 是我一個人重寫的（登入、在地化、自訂節點），再把合作夥伴的 library 整進去，平台就能直接驅動 LED、超音波感測器和蜂鳴器。
